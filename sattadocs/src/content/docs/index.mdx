## What is SattaSpace?

SattaSpace is a unified platform that handles **authentication**, **billing**, and **identity management** for modern applications. Stop building infrastructure—start shipping products.

<CardGrid stagger>
    <Card title="SattaBase" icon="user">
        **Authentication & Billing Hub**

        Single sign-on for the entire ecosystem. Manage subscriptions, handle payments via Stripe, and access all services from one dashboard.
    </Card>
    <Card title="Coming Soon" icon="rocket">
        **More Products Ahead**

        We're expanding the ecosystem with new tools. Stay tuned for updates.
    </Card>
</CardGrid>

## Core Features

<CardGrid stagger>
    <Card title="Unified Identity" icon="key">
        One account. All services. No more managing multiple logins.
    </Card>
    <Card title="Enterprise Security" icon="shield">
        OTP verification, password policies, and session management built-in.
    </Card>
    <Card title="Stripe Billing" icon="credit-card">
        Subscriptions, proration, and multi-currency support out of the box.
    </Card>
    <Card title="GDPR Ready" icon="document">
        Data portability and account control. Export anytime.
    </Card>
    <Card title="Dark Mode" icon="sparkle">
        Beautiful, accessible interface that works day and night.
    </Card>
    <Card title="Developer APIs" icon="code">
        RESTful APIs and webhooks for seamless integration.
    </Card>
